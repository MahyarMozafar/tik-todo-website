Privacy

Last updated: September 26, 2026

In short: Tik collects nothing about you. It has no account, it never connects to the internet, and your tasks stay on your phone.

The Tik app

  • Your tasks, lists, notes and the photos you add to tasks are stored only on your phone.
  • Tik has no code that connects to the internet. The Android app doesn't even ask for the INTERNET permission.
  • There are no ads, no trackers and no analytics.
  • The widget reads the same tasks, on the phone itself.
  • If your phone's own backup (Google or iCloud) is on, it may back up Tik's data like it does for other apps. That is done by the phone, not by Tik.

Permissions the app asks for

Android

  • Notifications (POST_NOTIFICATIONS): for reminders.
  • Exact alarms (USE_EXACT_ALARM, and SCHEDULE_EXACT_ALARM on Android 12 and older): so reminders come on time.
  • Start after a restart (RECEIVE_BOOT_COMPLETED): to set reminders again after the phone restarts.
  • WAKE_LOCK, FOREGROUND_SERVICE and ACCESS_NETWORK_STATE: Android's WorkManager library adds these for background work, like refreshing the widget. ACCESS_NETWORK_STATE can only see whether the phone is online; it is not permission to use the internet.
  • Photos: Tik uses Android's own photo picker, so only the photo you pick is shared with the app. No permission to see all your photos is needed.

iPhone and iPad

  • Notifications: for reminders. iOS asks you first.
  • Photos: when you pick a photo for a task, only that photo is shared with the app.

This website

  • This site is hosted on GitHub Pages. Like any server, GitHub may keep technical data such as IP addresses for security; see GitHub's privacy statement.
  • Visits are counted with GoatCounter: no cookies and no personal data. Only page views and a few clicks (like the download button) are counted.
  • The Android file downloads from this site itself. It is the same file as the official release on GitHub.
  • The site keeps a few small choices only in your own browser: your language, your color, and whether you closed the language bar. They are never sent anywhere.
  • Fonts and all other files come from this site itself; nothing is loaded from other font or script services.
